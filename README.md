# PLAYERS HISTORY 4.0 — Russian Football

Новая версия, не перезаписывайте старые папки 3.1/3.0. Каталог — только российские футболисты из исходной базы (207 игроков, 16 клубов).

## Локальный запуск (Windows)

Откройте PowerShell в папке проекта:

```powershell
C:\Users\Honor\PyCharmMiscProject\.venv\Scripts\python.exe -m pip install -r requirements.txt
C:\Users\Honor\PyCharmMiscProject\.venv\Scripts\python.exe -m uvicorn app:app --reload --port 8004
```

Адрес: http://127.0.0.1:8004

## ИИ

Создайте `.env` на основе `.env.example`. Впишите НОВЫЙ OpenRouter API key; старые ранее опубликованные ключи перевыпустите. Не присылайте `.env` никому. `app.py` читает `OPENROUTER_API_KEY` из переменных окружения. Для локального запуска загрузите их перед стартом:

```powershell
Get-Content .env | Where-Object { $_ -match '^[A-Z_]+=' } | ForEach-Object { $k,$v = $_ -split '=',2; [Environment]::SetEnvironmentVariable($k,$v,'Process') }
```

После этого запустите Uvicorn. ИИ ограничен 6 запросами в минуту на IP; для публичного запуска нужны полноценная авторизация и ограничения расходов. Никогда не публикуйте API-ключ в JavaScript.

## Подключение к Telegram

1. Разместите **весь проект** на сервере/хостинге с публичным HTTPS (localhost и 127.0.0.1 внутри Telegram у других пользователей не работают). Команда сервера: `uvicorn app:app --host 0.0.0.0 --port $PORT` (синтаксис переменной порта зависит от хостинга). Установите зависимости из requirements.txt.
2. Настройте секреты `BOT_TOKEN`, `OPENROUTER_API_KEY` и `WEBAPP_URL=https://ваш-домен` в переменных окружения хостинга. Не коммитьте `.env` в git.
3. Один раз выполните `python connect_telegram.py` на машине, где есть `BOT_TOKEN` и `WEBAPP_URL`. Это установит кнопку меню Mini App в вашем существующем боте без изменения его обработчиков.
4. Откройте бота в Telegram и нажмите кнопку меню. Сам бот продолжает работать отдельно, если запущен его процесс `bot.py`.

## Особенности

* Фотографии ищутся через Wikipedia и не гарантированы для всех игроков. Проверьте лицензии и атрибуцию перед публичным запуском.
* Рейтинги и сравнения основаны на исходной локальной базе и могут быть устаревшими.
* Избранное хранится локально в браузере, не синхронизируется между устройствами.
* Клубные сведения берутся из существующей базы; эмблемы не добавлялись без проверенных прав на изображения.
* Базовый ИИ-чат работает через OpenRouter; требуется ваш действующий ключ и баланс.
