
Открыть http://127.0.0.1:8003

## Как работают фото

1. Положи файл `ID.jpg` или `ID.png` в `static/photos` — он будет показан сразу.
2. Если локального файла нет, сервер пытается получить фотографию из Wikipedia через API. Поиск проверяет описание футболиста и год рождения, чтобы не перепутать людей.
3. Если интернет недоступен или совпадение ненадёжное, остаётся золотая буква. Это ожидаемое поведение.
4. Впервые открываемые фотографии могут загружаться несколько секунд. Внешние изображения принадлежат авторам, лицензии и атрибуцию нужно проверить перед публичным использованием.

Существующий бот не изменён. База данных читается только для чтения. Для онлайн-фотографий нужен доступ к en.wikipedia.org и upload.wikimedia.org.
