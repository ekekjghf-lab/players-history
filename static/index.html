Твоя футбольная вселенная

Версия 4.0 объединяет исторический каталог и отдельный слой актуальных составов РПЛ 2026/27. Составы синхронизируются с источником; игровая статистика матчей и голов пока не обновляется в реальном времени. Фотографии из static/photos имеют приоритет. Если фото нет, приложение пытается найти подходящий портрет через Wikipedia/Wikimedia. Для этого нужен интернет. При отсутствии проверенного фото показывается золотая буква. Фотографии могут иметь разные лицензии — проверяй атрибуцию перед публичной публикацией.
